# Support

Use GitHub Discussions for usage questions and GitHub Issues for reproducible defects or focused feature proposals. Include the Groundtrail version, Node.js version, operating system, command, redacted output, and the smallest safe reproduction when relevant.

Do not include credentials, access tokens, private repository content, personal data, production evidence, or unpublished release artifacts in public reports. Report suspected vulnerabilities through the private process in [SECURITY.md](SECURITY.md).

For installation questions, begin with `groundtrail install --dry-run` and include the reported operations rather than modifying target files to work around a conflict. Groundtrail does not provide organizational policy, deployment, production-control, or credential-management support; those remain with the repository owner’s external governance system.

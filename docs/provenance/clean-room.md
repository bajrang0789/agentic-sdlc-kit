# Clean-room authorship

Groundtrail is independently authored for this repository. Contributors create repository prose, code,
schemas, skills, examples, and generated Carriers from the stated requirements and the official
specifications or vendor documentation recorded in the research log.

Contributors must not copy, mirror, import, vendor, or mechanically rewrite another project’s repository,
Git history, examples, license headers, visual assets, or prose. A compatibility reference may state a
documented file convention or capability using nominative product names when necessary, but it must remain
original and must not imply endorsement or affiliation.

Dependencies come from npm registry tarballs with exact versions. They remain third-party components and
are recorded separately; they are not source material for Groundtrail-authored content.
